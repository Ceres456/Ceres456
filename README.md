## 🚀 대표 프로젝트

### [SmartPantry](https://smpa.aikopo.net)
컴퓨터 비전 + LLM 추론 + 웹 기술을 결합한 식재료 관리 캡스톤 서비스

- YOLO → LLM Vision 기반 음식 인식 방식으로 전환
- 한국 영수증용 2-pass OCR 파이프라인 설계 및 디버깅
- 4K 이미지 업로드 대응을 위한 Docker/Nginx 설정
- 프론트엔드 화면(ScanResultPage, MainPage) 개발
- YOLO 학습용 데이터셋 800~900개 상품 폴더 라벨링 및 전처리 자동화 스크립트 작성
